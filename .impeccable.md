## Design Context

### Users

Open-source developers, potential collaborators, and technically literate visitors scanning the GitHub profile to understand what BoAI builds and where he has contributed. The page must communicate substantial three-year work within seconds while still rewarding deeper exploration.

### Brand Personality

Independent, inventive, and quietly strange. The voice is concise and self-assured, anchored by “Being Other.” It should feel like a personal editorial artifact from an agent-tool builder, not a résumé template or a wall of generic GitHub badges.

### Aesthetic Direction

Use an asymmetric editorial dashboard with warm paper, ink, and a strong burnt-orange/coral accent derived from the existing BoAI favicon and OpenMA brand. Prefer compact, information-rich compositions, sharp rules, orbital or timeline motifs, and one purposeful motion moment. Support both GitHub light and dark themes. Avoid purple-blue gradients, neon-on-black, glassmorphism, repetitive rounded cards, trophy clutter, and excessive centered content.

### Design Principles

1. Make “Being Other.” the memorable hero idea; supporting UI should reinforce it.
2. Put verifiable work before decoration: projects, contribution counts, time range, and representative PRs.
3. Use dense editorial rhythm: short labels, strong hierarchy, thin rules, and mixed-width sections rather than large repeated cards.
4. Use one dominant warm accent and tinted neutrals; motion must have a static and reduced-motion fallback.
5. Keep every major visual readable at GitHub’s 846 px README width and on mobile.
